# Environment Pair Audit

This ledger records visual certification against
[`environment_perspective_standard.md`](environment_perspective_standard.md).
Certification is version-specific: replacing either image requires a new review.
`Certified` means exact dimensions, correct exploration/battle camera separation,
usable staging, at least three unmistakable same-place landmarks, coherent style,
and plausible geometry all passed visual inspection.

## Certification status

All 32 production exploration/battle pairs have received Emma's full camera,
staging, same-place, style, and geometry review. No pairs remain pending.

Briar Gym and Lantern Nursery were re-certified on 2026-08-01 after the
objective validator exposed their legacy 1254x1254 exploration canvases. Their
v2 paintings extend the original high-board compositions into 1536x1024
landscape frames while preserving every documented battle-pair anchor. The v1
files remain available for rollback but are no longer runtime-active.

Run `npm run validate:environment-pairs` to enforce the objective certification
contract: 32 unique ledger rows, 64 present PNG files at 1536x1024, at least
three documented anchors per pair, an active asset-registry reference for every
certified filename, and an exact SHA-256 match against
`environment_pair_certification_hashes.json`. The normal production build runs
this check, so silently overwriting a reviewed image under the same filename now
fails the build.

After an intentional replacement passes the complete visual review, run
`npm run update:environment-pair-hashes` to record the newly approved bytes.
Never refresh the manifest merely to clear a mismatch: a mismatch means the
asset's visual certification is no longer proven.

## Review sequence

For future replacements, review one pair at a time and preserve a passing image.
When an image fails, create a versioned replacement, register the new file, keep
the former version for rollback, run content/scene/build checks, and add
before/after evidence to the Persona activity feed. Any replacement invalidates
that pair's certification until the new version passes the complete review.
